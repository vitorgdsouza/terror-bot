Política de Privacidade

Última atualização: 17 de novembro de 2026.

O terror-bot é uma ferramenta de uso pessoal do canal "Você Escaparia?". Ela é usada apenas pelo dono do canal.

Dados acessados

Com a autorização do dono do canal, a ferramenta usa as APIs do YouTube (YouTube Data API e YouTube Analytics API) para ler a lista de vídeos, estatísticas e relatórios de desempenho do próprio canal, e para enviar vídeos e miniaturas para esse canal.

Uso dos dados

Os dados servem só para gerar relatórios de desempenho para o dono do canal e publicar o conteúdo dele. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Armazenamento

Os relatórios são guardados no repositório do projeto. As credenciais de acesso ficam em segredos criptografados e podem ser revogadas a qualquer momento em myaccount.google.com/permissions.

Serviços do Google

O uso das APIs do YouTube segue os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google.
